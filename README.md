# Watchlist

Watchlist is a modern web application that allows users to create and manage a personal movie watchlist.

Live Demo: https://watchlistasm.netlify.app/

---

## About The Project

Watchlist is designed for movie lovers who want to keep track of movies they plan to watch.  
Users can browse movies, add them to their personal watchlist, and view their saved list at any time.

The project focuses on frontend development using modern web technologies and a clean, user-friendly interface.

---

## Features

- Clean and simple user interface  
- Add movies to a personal watchlist  
- View and manage saved movies  
- Responsive design  
- Fast and lightweight frontend application  

---

## Built With

- React  
- JavaScript (ES6+)  
- HTML5  
- CSS3  
- Netlify (Deployment)
